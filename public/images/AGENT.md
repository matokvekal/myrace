# Public Images Folder Guide

Purpose

- Static marketing/landing images served as-is (not bundled), referenced via
  `import.meta.env.BASE_URL` at runtime. Has an auto-generated
  `manifest.json` (see `scripts/gen-images-manifest.mjs`).

Read Order

1. ../../AGENT.md
2. ../AGENT.md

No child folders.

Conventions

- `manifest.json` in this folder is generated by `npm run gen-images` — don't
  hand-edit it, re-run the script after adding/removing an image.
- Reference these via `${import.meta.env.BASE_URL}images/<file>`, never a
  hardcoded `/images/...` path.
